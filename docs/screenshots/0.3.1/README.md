# Easy Connect 0.3.1 UI previews

Rendered from the actual C interface with the host InkView test adapter,
PB632 native theme and native Roboto font at 1072 × 1448. These are UI previews,
not physical-device captures. Other readers can differ in size and firmware styling.

Generated with `tools/preview-ui.py --width 1072 --height 1448`, using
`--theme-reference` and `--native-font` from the local firmware reference.
Only PNG previews are published; firmware resources and font files remain local.

Toolbar: Home, Refresh Library, Save diagnostics, Check for updates, Version.
Both services are stopped. `192.0.2.1` and `ec-build` are example connection values.
